Política de privacidad de reKreo

Última actualización el 11 de noviembre de 2026

Esta política se aplica al sitio web y a la app Android de reKreo, el servicio de pedidos y gestión para kioscos escolares operado por Tu App Sin Vueltas, en Argentina. Para consultas sobre tus datos, escribí a angelsar.desarrolladorweb@gmail.com.

Datos que usamos y para qué

  • Cuenta y acceso. Usamos tu nombre, apellido, correo, identificador de cuenta y tipo de usuario para iniciar sesión, verificar el correo, recuperar el acceso y asignar permisos. Firebase Authentication gestiona el acceso con correo y contraseña o con Google, según tu elección.
  • Escuela y kiosco. Usamos tu vínculo con un kiosco y, cuando corresponde, el curso, la división, el turno o el lugar de entrega para mostrarte el catálogo correcto y organizar el retiro o la entrega.
  • Pedidos y saldo. Registramos productos, importes, descuentos, horarios, estados de pedidos, cargas, cobros y devoluciones para operar el servicio y llevar el historial. Los códigos QR permiten identificar una cuenta, un kiosco, un pedido o un cobro. El saldo corresponde al kiosco asociado y se usa para comprar allí.
  • Gestión del kiosco. Podemos registrar datos de contacto, comerciales, fiscales y de cobro del titular, según lo que se suministre para gestionar el servicio. También conservamos registros de las operaciones administrativas.
  • Cámara e imágenes. Si das permiso, la cámara se usa para leer códigos QR o tomar fotos para el catálogo. El kiosco también puede elegir fotos de productos para subirlas al catálogo.

Quién puede acceder a los datos

El personal autorizado del kiosco asociado puede consultar los datos de tu cuenta necesarios para gestionar pedidos y saldo, como nombre, correo y datos escolares que correspondan. La administración de reKreo accede a los datos necesarios para operar el servicio y atender solicitudes de soporte. El kiosco puede descargar registros de sus operaciones para su gestión.

Usamos Google Firebase para autenticación y base de datos, Cloudinary para alojar fotos del catálogo, Cloudflare para gestionar el borrado de esas fotos y GitHub Pages para alojar la web. El uso del servicio puede implicar tratamiento de datos en infraestructura ubicada fuera de Argentina. Los permisos de acceso dependen del rol y del kiosco asociado.

Datos de los usuarios

reKreo usa los datos de los usuarios para identificarlos en el kiosco y gestionar sus pedidos, su saldo y la entrega. Te podemos pedir información suficiente para verificar tu representación.

Conservación y derechos

Conservamos los datos de cuenta mientras esté activa y los registros durante el tiempo necesario para prestar el servicio, resolver incidencias y cumplir las obligaciones aplicables. Podés solicitar acceso, rectificación, actualización o supresión de tus datos por correo. Si corresponde conservar registros de determinadas operaciones por obligaciones legales, seguridad o controversias, se limita su uso a ese fin y se conservan por el plazo necesario.

Solicitar la eliminación de tu cuenta

Escribí a angelsar.desarrolladorweb@gmail.com con el asunto Eliminar mi cuenta de reKreo. Indicá el correo con el que te registraste y el kiosco asociado si lo recordás. Evitá enviar tu contraseña. También encontrás este acceso en Mi perfil dentro de la app.

Verificaremos la titularidad y, si hay pedidos o saldo pendientes, coordinaremos su resolución con vos. La solicitud se gestiona manualmente. Una vez verificada, se elimina el acceso y se eliminan o anonimizan los datos personales asociados, salvo los registros que debamos conservar por los motivos indicados arriba.
